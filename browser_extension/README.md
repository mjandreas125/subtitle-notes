# Browser Capture Extension

Works in Chrome, Edge, Brave, Opera and other Chromium browsers.

1. Open `chrome://extensions` (or `edge://extensions`).
2. Enable **Developer mode**.
3. Choose **Load unpacked** and select this folder.
4. Open extension options and click **Connect this browser**. The permanent
   cloud address is filled in automatically; approve the displayed code in the
   phone app.
5. Select a subtitle/phrase on a webpage, right-click, choose **Send to Subtitle Notes**.

The extension saves text that the browser exposes to a webpage. It adds page title
and the active HTML5 video time where available. DRM/video-canvas subtitles that
are not exposed as selectable browser text cannot be read by any normal extension;
in that case select/copy text if the site permits it.
