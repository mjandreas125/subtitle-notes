# Copy review report - 2026-09-06

## Scope and backup

Reviewed the six copy surfaces described in `docs/COPY-REVIEW.md`: the landing page, link page, library, browser extension, Android app and Windows program. The review covered all 15 shipped languages. Changes are limited to high-confidence corrections: clear mistranslations, broken placeholders, missing translations, inconsistent tutorial examples and product-name errors.

Before changing any source, I created a byte-for-byte text backup with hashes:

- `docs/copy-backups/20260906-015941/`
- `SHA256.json` records the 21 copied source files.

## Changes made

| Surface / key | Languages | Before | After | Why |
|---|---|---|---|---|
| app / missing keys | de, es, et, fi, fr, it, nl, pl, pt, sv, tr, uk | 52 keys silently fell back to English | Every app language now has every key | A reader must not encounter English inside an otherwise localized interface. |
| app / `Subtitle\\nNotes` and Android instructions | all affected app languages | Product name was translated, for example `Субтитры Примечания`, `Tekstitys`, `Ondertitelnotities` | Literal `Subtitle Notes` | Android, the launcher and menus show the actual product name. |
| app / pairing and nickname hints | et, fi, fr, it, nl, pl, pt, ru, sv, uk | Several hints called the product a translated “subtitle notes” or produced a broken sentence | Natural sentence with literal `Subtitle Notes` | The pairing flow and friend search need an exact, recognizable name. |
| app / `All $saved saved ...` | es, et, fi, it, pl, pt, sv | The Dart expression used translated variable names such as `${salvati ...}` | Restored literal `${saved == 1 ? ...}` | Interpolation identifiers are code, not copy; translated names can break the string at runtime. |
| app / action labels | de, es, et, fi, fr, it, nl, pl, pt, sv, tr, uk | Literal or wrong labels such as “close practice” as “near practice”, review as “review/article”, save as “save money” | Direct verbs for closing practice, revising and saving | Buttons now describe the action a person can take. |
| app / tutorial and library sentences | de, es, et, fi, fr | “Pick the one that belongs”, “word you stop”, “like this word” and similar literal translations | Direct, contextual instructions | These are core onboarding strings and were hard to understand literally. |
| site-home / `lede` | ru, et, fr, es, it, pt, uk | Said a word is translated “as it sounds” in a sentence | Says it is translated in the meaning it has in the sentence | The product’s central promise is contextual meaning, not pronunciation. |
| desktop / `tour_line` | fr, es, tr | Shortened or incomplete criminal-record example | Same full example used elsewhere | The contextual translation example now matches the app and extension. |
| extension / `optBlocked` | de, fr, es, it, pt | Ungrammatical “do not work on these sites” labels | Clear disable/not-activate setting label | A setting title should name its effect. |
| extension / `optSpaceSaves` | es, pt | “space” was translated as empty space | Explicit “space bar” | The shortcut is now understandable. |
| extension / `tourLine` | pl | `Nikt nie chce kartoteki.` | `Nikt nie chce kartoteki karnej.` | Matches the complete tutorial example on the other surfaces. |

## Consistency results

- Placeholder invariant: translated identifiers in the `$saved` plural expression were restored to the exact Dart identifier.
- Gaps: `docs/copy-review/gaps.md` now reports **every language has every key** for app, desktop, extension, site-home, site-library and site-link.
- Export: `python tools/collect-copy.py` completed successfully. The generated inventory is now 8,772 strings; the increase is the 52 previously missing app translations.

## Language-confidence note

The audit was performed in parallel by language groups. Changes were made only where the defect was unambiguous. Estonian and Turkish still deserve a final native-speaker pass for stylistic preference and terminology consistency (especially the local word for “library”); no speculative bulk rewrite was made there. This preserves meaning and avoids replacing understandable text with an unverified translation.
