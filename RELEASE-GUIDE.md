# Как выпустить это в мир

Три части ставятся по-разному, и до магазинов путь у каждой свой. Ниже -
порядок действий целиком, от аккаунта до ссылки, которую можно дать человеку.

## 0. Один раз: разрешить вход через Google

Пока это не сделано, кнопка "Войти через Google" в браузере и в программе даёт
`Ошибка 400: origin_mismatch`.

1. <https://console.cloud.google.com/apis/credentials?project=151185018789>
2. Раздел **OAuth 2.0 Client IDs** -> клиент типа **Web application**
   (`151185018789-tjda40ks...`).
3. **Authorized JavaScript origins** -> **ADD URI** ->
   `https://subtitle-notes-api.andreas-sultseng228.workers.dev` (без слэша).
4. **Save**, подождать пару минут.

## 1. Телефон: Google Play, $25 разово

**Перед сборкой.** В `mobile/android/app/build.gradle.kts` вернуть две строки,
они помечены комментарием:

```kotlin
applicationId = "ee.subtitlenotes.app"
signingConfig = signingConfigs.getByName("release")
```

Из-за этого вход через Google сломается, пока новая пара "пакет + сертификат"
не зарегистрирована, поэтому сразу после этого:

1. В той же консоли Google -> **Create credentials** -> **OAuth client ID** ->
   **Android**. Package name: `ee.subtitlenotes.app`. SHA-1: отпечаток
   upload-ключа `2E:02:D5:95:83:E2:66:AC:E2:A0:46:08:1B:E4:B2:CD:0A:49:01:CE`.
2. Собрать пакет для магазина:
   `flutter build appbundle --release` (получится `build/app/outputs/bundle/release/app-release.aab`).
3. <https://play.google.com/console> -> создать аккаунт разработчика, $25
   разово, подтвердить личность.
4. Create app -> название Subtitle Notes, язык, "App", "Free".
5. Загрузить `.aab` в **Internal testing** (там же будет ссылка для установки
   без магазина - удобно раздать знакомым уже сегодня).
6. **После первой загрузки** Play подпишет приложение своим ключом. Открыть
   **Setup -> App signing**, скопировать оттуда SHA-1 и завести в Google Cloud
   **третий** Android-клиент с этим отпечатком. Без этого шага вход через
   Google не будет работать у тех, кто установил приложение из магазина.
7. Заполнить карточку: описание, иконка 512x512, баннер 1024x500, минимум два
   скриншота телефона, политика конфиденциальности
   <https://subtitle-notes-api.andreas-sultseng228.workers.dev/privacy>,
   разделы Data safety и Content rating.
8. Личный аккаунт: закрытый тест на 12 человек 14 дней подряд, потом можно
   просить Production. Аккаунт организации (на OU) от этого освобождён.

## 2. Браузер: Chrome Web Store, $5 разово

1. <https://chrome.google.com/webstore/devconsole>, $5 разово.
2. Загрузить `release_package/subtitle-notes-extension-<версия>.zip`
   (пересобирается: `powershell -ExecutionPolicy Bypass -File pack-extension.ps1`).
3. Заполнить форму - весь текст, включая обоснования разрешений, лежит в
   `STORE-LISTING.md`.
4. Отправить на проверку. Дальше каждая новая версия: поднять номер в
   `extension/manifest.json`, пересобрать, загрузить. Обновление у людей
   произойдёт само.

Opera и Edge берут расширения из этого же магазина, отдельная публикация не
нужна.

## 3. Компьютер: откуда люди берут программу

Магазина для неё нет, поэтому нужен адрес, по которому лежит установщик.

**Как собрать:**

```
powershell -ExecutionPolicy Bypass -File build.ps1     # собирает .exe в dist\
```
затем открыть `installer/SubtitleNotes.iss` в Inno Setup и нажать Compile -
получится `release_package/SubtitleNotesSetup-<версия>.exe`.

**Где выложить,** по возрастанию усилий:

- **GitHub Releases** - бесплатно, ссылка вида
  `github.com/<аккаунт>/subtitle-notes/releases/latest`. У тебя уже есть такой
  порядок для другого проекта, здесь он ляжет так же.
- **Своя страница** на воркере со ссылкой на этот файл, чтобы адрес был
  коротким и одинаковым в описании магазина и в приложении.

**Что человек делает:** скачивает `.exe`, запускает, видит предупреждение
SmartScreen ("Подробнее" -> "Выполнить в любом случае" - установщик не
подписан), проходит установку, в конце открывается окно "Подключить этот
компьютер" с кнопкой Google. VLC настраивается сам, Ctrl+Alt+S встаёт в
автозапуск.

## 4. Что сказать людям в описании

Порядок, который работает без объяснений:

1. Поставить приложение из Play и войти через Google.
2. Поставить расширение из Chrome Web Store - оно предложит войти тем же
   аккаунтом.
3. Кому нужен VLC и PDF на компьютере - скачать установщик по ссылке и войти
   там же.

Библиотека у всех трёх одна, потому что аккаунт один.
