Subtitle Notes
==============

Выделите незнакомое слово там, где смотрите или читаете, и сразу увидите,
что оно значит в этой реплике. Слово остаётся в общей библиотеке телефона,
браузера и компьютера и возвращается на повторение.

Как начать
-

1. Откройте «Subtitle Notes» в меню «Пуск» и войдите через Google.
2. Нажмите «Открыть фильм» - программа запустит VLC и подготовит субтитры.
3. Во время фильма держите Ctrl и протяните мышью по слову в субтитре.
4. Ctrl+Alt+S сохраняет выделенный текст из любой другой программы.

Фильм можно открыть и правым щелчком по файлу: «Open with Subtitle Notes».

На телефоне и в браузере
-

Приложение для Android: папка Android рядом с этим файлом. Это тестовый APK,
поэтому Android попросит разрешить установку из этого источника; в Google Play
оно появится отдельно.

Расширение для Chrome, Edge и Opera: папка Browser Extension рядом с этим
файлом. Откройте `chrome://extensions` (или `edge://extensions`), включите
«Режим разработчика» и нажмите «Загрузить распакованное». Выберите именно
папку Browser Extension, где лежит файл `manifest.json`. После установки
откройте `INSTALL.md` в этой папке: там описаны вход через Google, Ctrl для
субтитров, Ctrl+Alt для текста и отдельное разрешение для PDF с диска.

Вход везде через один и тот же аккаунт Google. Библиотека открывается и в
браузере: https://app.subtitlenotes.workers.dev/library
