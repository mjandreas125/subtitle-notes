# Subtitle Notes

Выделите незнакомое слово там, где смотрите или читаете - в субтитрах
веб-плеера, на сайте, в PDF, в VLC - и сразу увидите, что оно значит в этой
реплике. Слово остаётся в общей библиотеке телефона, браузера и компьютера
и возвращается на повторение.

Перевод не пословный: строку читает языковая модель, которая видит контекст.
«No one wants a record» - это не «никто не хочет рекорд», а «никому не нужна
судимость».

## Установка

Сейчас это закрытая альфа-версия, а не выпуск в магазинах.

- **Браузер** - Chrome, Edge и Opera. Тестовый ZIP расширения нужно
  распаковать, затем в `chrome://extensions` включить Developer mode и выбрать
  папку, в которой лежит `manifest.json`. Точная инструкция находится внутри
  архива в `INSTALL.md`.
- **Телефон** - Google Play ещё готовится. APK для закрытой проверки выдаётся
  вместе с тестовым приглашением; Android предупредит об установке из
  неизвестного источника.
- **Компьютер** - [Windows-установщик](https://github.com/mjandreas125/subtitle-notes/releases/latest):
  субтитры в VLC и текст в любой программе по Ctrl+Alt+S. Установщик пока не
  подписан, поэтому SmartScreen покажет предупреждение.

Вход везде через один аккаунт Google. Библиотека доступна и в браузере:
<https://app.subtitlenotes.workers.dev/library>

Публичные файлы выпуска и руководство появляются на странице
[Releases](https://github.com/mjandreas125/subtitle-notes/releases). До
публикации тестировщик должен получать только подготовленный тестовый набор,
а не собирать расширение из исходников.

## Для разработки

Всё состояние проекта, устройство частей, команды сборки и открытые задачи -
в [PROJECT.md](PROJECT.md).

```
cloud_api/    Cloudflare Worker + D1: аккаунты, карточки, разбор, повторение
extension/    расширение для браузера
mobile/       приложение (Flutter) и библиотека для Windows
installer/    сборка установщика (Inno Setup)
tools/        стенд с копией веб-плеера и скрипты проверки через CDP
```
