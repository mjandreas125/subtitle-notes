# Subtitle Notes

Выделите незнакомое слово там, где смотрите или читаете — в субтитрах
веб-плеера, на сайте, в PDF, в VLC — и сразу увидите, что оно значит в этой
реплике. Слово остаётся в общей библиотеке телефона, браузера и компьютера
и возвращается на повторение.

Перевод не пословный: строку читает языковая модель, которая видит контекст.
«No one wants a record» — это не «никто не хочет рекорд», а «никому не нужна
судимость».

## Установка

- **Телефон** — приложение (Google Play, готовится к публикации).
- **Браузер** — расширение для Chrome, Edge и Opera.
- **Компьютер** — [установщик для Windows](https://github.com/mjandreas125/subtitle-notes/releases/latest):
  субтитры в VLC и текст в любой программе по Ctrl+Alt+S.

Вход везде через один аккаунт Google. Библиотека доступна и в браузере:
<https://subtitle-notes-api.andreas-sultseng228.workers.dev/library>

Руководство для обычного пользователя: `release_package/guide/Subtitle-Notes.pdf`.
